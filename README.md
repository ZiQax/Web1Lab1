## Langkah-langkah Praktikum

Berikut adalah alur pengerjaan praktikum beserta hasil tangkapan layarnya:

### 1. Persiapan dan Struktur Dasar HTML
Langkah pertama adalah membuat file HTML (`lab1_tag_dasar.html`) dan menuliskan deklarasi `<!DOCTYPE html>` beserta struktur kerangka dasar HTML seperti tag `<html>`, `<head>`, dan `<body>`.

![Struktur Dasar HTML](/images/image.png)

### 2. Implementasi Tag Header dan Paragraf
Menambahkan judul menggunakan tag heading (`<h1>` dan `<h2>`), serta membuat beberapa blok teks menggunakan tag paragraf (`<p>`).

- **Paragraf**
  ![Paragraf 1](/images/image-1.png)
  ![Paragraf 2](/images/image-2.png)

- **Heading 1 & Heading 2**
  ![Header](/images/image-3.png)

### 3. Pemformatan Teks (Text Formatting)
Melakukan simulasi pemformatan teks di dalam paragraf menggunakan tag `<b>` (Bold), `<i>` (Italic), `<strong>`, `<sub>` (Subscript untuk H₂O), dan `<sup>` (Superscript untuk x²).

![Pemformatan Teks](/images/image-4.png)

### 4. Menyisipkan Gambar
Menambahkan foto profil mahasiswa menggunakan tag `<img>`. Diatur juga atribut `width="200"`, `alt="Foto profil mahasiswa"`, dan `title="Foto Profil Mahasiswa"`.

![Insert Gambar 1](/images/image-5.png)
![Insert Gambar 2](/images/image-6.png)

### 5. Navigasi Halaman dengan Hyperlink
Membuat simulasi navigasi menggunakan tag `<nav>` dan `<a>` (Anchor/Hyperlink) untuk berpindah ke halaman internal (`index.html` dan `halaman2.html`) serta tautan ke website eksternal (Google).

![Navigasi Hyperlink](/images/image-7.png)

### 6. Penggunaan Tag List (Unordered & Ordered) dan Komentar
Menyusun "Data Diri", "Keahlian", dan "Target Belajar" menggunakan kombinasi Unordered List (`<ul>`) dan Ordered List (`<ol>`). Pada tahap ini juga ditambahkan komentar `<!-- ... -->` pada kode untuk dokumentasi developer.

![List dan Komentar 1](/images/image-8.png)
![List dan Komentar 2](/images/image-9.png)

### 7. Penggabungan Seluruh Elemen
Tampilan keseluruhan halaman web (`index.html`) setelah seluruh tag dasar HTML digabungkan dan dijalankan pada web browser.
